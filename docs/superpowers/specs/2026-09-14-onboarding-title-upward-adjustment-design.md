# Onboarding 标题上移微调设计

## 目标

在不改变标题字号、两行间距、左侧整体布局或右侧 3D 场景的前提下，让两行主题字都略微上移，并让第一行的上移幅度更明显。

## 样式调整

- 宽桌面（大于 1180px）：第一行由 `translateY(-8px)` 改为 `translateY(-18px)`；第二行由 `translateY(8px)` 改为 `translateY(0)`。
- 中等桌面（769px–1180px）：第一行由 `translateY(-6px)` 改为 `translateY(-14px)`；第二行由 `translateY(6px)` 改为 `translateY(0)`。
- 移动端（不大于 768px）：第一行由 `translateY(-3px)` 改为 `translateY(-7px)`；第二行由 `translateY(3px)` 改为 `translateY(0)`。

这组数值会让宽桌面第一行额外上移 10px、第二行上移 8px；中等桌面和移动端按较温和比例收敛，避免标题碰到品牌区或屏幕边缘。

## 范围约束

- 保留现有标题字号与 `row-gap`。
- 不移动品牌、说明文字、按钮、爱心模型、轨道、气泡或星星。
- 不修改标题文案和颜色。
- 保留现有移动端无横向溢出表现。

## 验证

- 更新样式测试，使三个断点的位移值均有明确断言。
- 运行相关样式测试、完整前端测试和生产构建。
- 在桌面视口检查第一行提升更明显、第二行轻微提升，并确认标题未与品牌或说明文字重叠。

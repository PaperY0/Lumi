# 个性化模拟对话反馈设计

## 目标

将“模拟对话”的即时反馈从预测对方情绪或关系结果，调整为帮助用户检查自己的表达是否清晰、低压力且尊重边界。系统不得把单条短回复、句号、回复速度或一次争执当作对方情绪、好感或人格的确定证据。

## 非目标

- 不预测对方是否喜欢用户，不给出“成功率”。
- 不把“嗯”“嗯嗯”“句号”等写成所有人的固定情绪词典。
- 不在本次改动中分析未获用户确认的私人聊天含义。
- 不删除既有模拟练习历史；旧分数仅作为历史字段保留，不在新的即时界面展示。

## 交互与输出

### 即时检查

取消 0–100 总分。每次用户输入后，显示一个检查等级：

| 等级 | 含义 | 例子 |
| --- | --- | --- |
| 低风险 | 表达清晰、尊重选择、保留拒绝或暂不回应的空间 | 一次轻量邀约并明确“没空也没关系” |
| 需斟酌 | 信息不足、与确认的个人基线不一致，或可能造成压力 | 对方偏好未知时连续解释自己的感受 |
| 高压力 | 连续追问、否定拒绝、强迫表态、以冷淡/嫉妒/委屈施压 | 对方明确说不后继续劝说 |

反馈必须分为“可确认”“个人化线索”“不确定项”和“一步低风险建议”。没有足够的个人化依据时，个人化线索必须显示为“基线不足，无法判断”，而不是猜测情绪。

### 个人化聊天基线

聊天基线只记录用户确认的、描述性的习惯：短回复是否常态、句号/表情使用习惯、通常回复节奏、是否会主动延展话题。每项包含来源和确认状态：

- `manual`：用户主动填写，立即可用；
- `candidate`：聊天记录足够时由 AI 给出候选及可核验摘要，未确认前不可用于判断；
- `confirmed`：用户确认后可用于“需斟酌”的提示；
- `unknown`：默认值，不得推断。

聊天记录较少时引导用户手动填写；记录足够时，AI 只能提出候选，例如“最近 30 条对方消息中，18 条以句号结尾”，用户逐条选择“符合 / 不符合 / 暂不确定”。“足够”的首版门槛为至少 30 条可识别为对方的文本消息，且候选只统计最近 90 天内的消息。

### 冲突修复偏好

新增可编辑的个人化偏好卡：

- 第一偏好：先冷静 / 尽快沟通 / 视情况而定 / 尚不清楚；
- 希望间隔：30 分钟内 / 当天稍晚 / 次日 / 由对方主动说明 / 尚不清楚；
- 是否先收到确认：希望收到确认 / 希望先安静 / 视情况而定 / 尚不清楚；
- 不接受的修复方式：连续追问、长时间失联不说明、情绪化争输赢，以及可选补充文本。

偏好未知时，模拟建议只能使用一次低压力澄清：“我愿意把这件事谈好；你更希望现在聊，还是晚些时候再说？” 用户确认“先冷静”后才可建议等待；仍需保留“是否方便”和“何时再谈”的选择权。

## 数据与流程

1. 从女生资料建立独立的沟通偏好记录；不从单次消息自动覆盖已确认偏好。
2. 导入聊天记录后达到门槛，生成候选卡和统计依据；用户逐项确认。
3. 模拟请求携带已确认基线、冲突偏好、当前关系阶段、双方资料、问卷摘要、最近聊天记录和关系节奏卡。
4. 后端先按透明规则检查可控风险，再让 AI 生成与“已确认资料”一致的模拟回复及解释。
5. AI 返回每条结论的依据类型（直接资料 / 已确认基线 / 对话事实 / 信息不足）；前端拒绝展示没有依据的情绪判断。
6. 历史练习继续保存；新记录保存检查等级和分项反馈，不再写入新的数值分数。

## 安全边界

- “明确拒绝”“停止联系”“不方便继续”等信息优先于任何基线或模型推断；建议停止推进。
- 系统不得建议操控、冷暴力、制造嫉妒、窥探隐私或连续追问。
- 出现威胁、跟踪、强迫、控制、身体伤害、性施压或明显恐惧时，停止一般沟通练习并优先提示现实安全支持。
- AI 候选和模拟均须使用不确定表达；不得声称理解对方内心。

## 验收标准

1. Mock 模式不再固定展示 70 分；AI 模式和 Mock 模式均返回三档检查结果。
2. 未填写或未确认基线时，“嗯”“句号”“回复慢”不会触发情绪结论。
3. 30 条以内记录只提供手动录入；达到 30 条后可查看候选并逐项确认。
4. 用户确认的短回复/句号习惯，会以“个人化线索”影响提示；未确认候选不会影响结果。
5. 冲突偏好未知时只给一次低压力澄清；不同确认偏好得到不同等待和修复建议。
6. 明确拒绝始终触发停止推进，不被模拟情景、阶段或基线覆盖。
7. 旧模拟历史可读取；新练习界面不展示总分。
8. 为规则、候选确认、提示词和 Mock 输出添加单元测试，并做浏览器主流程验收。

## 实施边界

本功能分两次提交：先完成“三档检查、移除总分、冲突偏好手动填写”；再完成“聊天导入后的候选基线与用户确认”。这样可以先消除虚假精确，同时避免在没有可核验样本时引入自动推断。
